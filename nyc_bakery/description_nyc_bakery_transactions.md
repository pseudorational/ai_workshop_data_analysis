# NYC Bakery Transactions

The dataset contains 58,434 item records across 26,940 transactions, dated October 1, 2025–March 31, 2026. Each row records an item within a transaction; transaction IDs can repeat when multiple items are recorded.

## Columns

- **Transaction:** Transaction identifier.
- **Item:** Name of the item recorded.
- **date_time:** Transaction date and time (YYYY-MM-DD HH:MM).
- **period_day:** Morning, afternoon, or evening.
- **weekday_weekend:** Whether the transaction occurred on a weekday or weekend.

All five columns have no missing values. Prices and sales amounts are not included.
